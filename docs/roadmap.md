## Замечено

- Сохранение каждый раз пишется целиком вместе со списком всех команд. На этапе 1 это килобайты. Перед длинными партиями (этап 5) замерить и, если нужно, писать команды отдельно.
- Кнопка «назад» на Android и сворачивание приложения никак не обрабатываются: сохранять при них нечего, запись идёт после каждой команды., но не сделано

- Линтер не использует проверки с учётом типов (нужен отдельный пакет `oxlint-tsgolint`).
- Сборка клиента — один файл около 1,6 МБ: Phaser подключён целиком.
- Сцена карты (Phaser) и вёрстка не покрыты автоматическими тестами: для этого нужен запуск в браузере. Тестами покрыты логика управления (`session.ts`) и пересчёт координат (`geometry.ts`). Агент проверял экран вручную: снимками из браузера без окна, который поставлен во временную папку песочницы и в проект не входит.
- Холст рисуется в пикселях вёрстки, без учёта плотности экрана: на телефоне картинка может быть мягче, чем нужно. Проверить на шаге 1.3.
- Слой плиток: обычный `TilemapLayer`. В песочнице `TilemapGPULayer` разницы не дал (замер в браузере без видеокарты: код игры занят меньше 1 % времени кадра в обоих случаях). Решать по счётчику кадров на телефоне.
- В браузере песочницы большая карта при окне 800×450 даёт 43–46 кадров в секунду, а при 1600×900 — 60. Профиль показывает, что код игры простаивает; похоже на особенность программной отрисовки в песочнице. На телефоне проверить отдельно.
- Слияние в `main` 2026-11-11 прошло без проверки на GitHub: запуски стояли в очереди. Локальная проверка была зелёной.
- Тест свойств поиска пути сверяет стоимость с другим алгоритмом, но правила шага у них общие. Сами правила шага проверяются примерами из спецификации.
