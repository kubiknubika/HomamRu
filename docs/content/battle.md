# Бой: чего не хватает

Механика боя у нас сделана глубже, чем контент в ней. Считаю по частям.

## Боевые машины

| Машина | Heroes 3 | У нас |
|---|---|---|
| **Катапульта** | стены в осаде | **есть** (шаг 6, решение 0009) |
| **Баллиста** | стреляет по отрядам, покупается в кузнице | нет |
| **Палатка первой помощи** | лечит своих, покупается в кузнице | нет |
| **Повозка боеприпасов** | не даёт стрелкам кончиться | нет |

Три из четырёх нет. Баллиста и палатка требуют: существа-машины в бою, покупки в кузнице, навыков «Артиллерия» и «Первая помощь». Повозка боеприпасов — самая дешёвая: это счётчик выстрелов, который не кончается.

## Способности существ

У нас два поля: `flying` и `shots`. В Heroes 3 — около сорока способностей. Самые заметные и что они меняют:

| Способность | Что делает | Сколько существ в Heroes 3 |
|---|---|---|
| **Стреляет без штрафа** | нет штрафа за расстояние | ~8 |
| **Двойной удар** | бьёт дважды | 3 |
| **Два ответных удара** | не устаёт отвечать | 2 |
| **Нежить** | не лечится, не воскрешается, не поднимается | 13 |
| **Сопротивление магии** | шанс отбить заклинание | 6 |
| **Иммунитет к школе магии** | не берёт огонь/вода/земля/воздух | ~10 |
| **Уменьшает урон стрел** | вдвое меньше от стрел | 3 |
| **Аура страха** | враг не может подойти близко | 2 |
| **Огненный щит** | отдаёт урон назад | 3 |
| **Регенерация** | восстанавливает здоровье каждый раунд | 4 |
| **Пьёт кровь** | лечится нанесённым уроном | 3 |
| **Каменный взгляд** | убивает долей шанса | 2 |
| **Задевает соседей** (драконье дыхание) | урон по площади | 4 |
| **Задевает всех рядом** | урон по трём клеткам | 2 |
| **Летает** | есть | 22 |
| **Стреляет** | есть | 28 |

Каждая способность — правило боя. Это самый дорогой вид контента: добавить существо с новым полем легко, но каждая способность меняет формулы урона, ответного удара, лечения и очерёдности.

**Предложение:** брать по одной-две способности за проход, начиная с тех, что не меняют порядок боя: «нежить», «сопротивление магии», «иммунитет к школе», «регенерация», «уменьшает урон стрел».

## Чего ещё нет в бою

| Чего нет | В Heroes 3 | Цена |
|---|---|---|
| **Улучшенные существа** | второе существо каждого уровня | одно существо + одно здание на уровень |
| **Восьмой уровень** | в части дополнений | ещё одно жилище |
| **Боевые машины в обороне города** | баллиста на стене | ждёт баллисты |
| **Расстановка перед боем** | навык «Тактика» | ждёт навыка |
| **Стрельба по своим** | разрешена | у нас запрещена жёстко |
| **Бегство с поля** | герой бежит, теряя армию | **у нас есть** (`CANNOT_FLEE` запрещает только обороняющемуся в городе) |
| **«Подождать» с порядком** | отряд уходит в конец очереди | у нас есть |
| **Клетки для больших существ** | дракон занимает 2 клетки | у нас все 1 |

## Итог

| Часть | Готово |
|---|---|
| Правила боя (урон, ответ, стрельба, дух, удача, магия, осада) | **~95 %** |
| Боевые машины | 25 % (1 из 4) |
| Способности существ | 5 % (2 из ~40) |
| Улучшения существ | 0 % |

То есть бой **как механика** почти закончен, а **как набор существ** — почти пуст. Это ровно то, что видно в процентной таблице: механики 99, контент 27.

## Что нужно решить владельцу

1. **Способности** — по одной-двум за проход или пачкой? Какие первыми?
2. **Повозка боеприпасов** — самое дешёвое из машин, брать ли?
3. **Баллиста и палатка** — они требуют покупки и двух навыков, то есть идут в одном проходе с кузницей и навыками.
4. **Большие существа на двух клетках** — это меняет геометрию поля и расстановку; оставить всех одноклеточными?
