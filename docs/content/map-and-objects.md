# Карта и объекты: чего не хватает

Это самое заметное после существ: в Heroes 3 карта — это музей объектов, ради которых и ходят герои.

Состав объектов Heroes 3 — VCMI `config/objects/*.json` (2026-11-11). Наши объекты — по `data/maps/*.yaml`.

## Какие объекты у нас есть

| Тип | Что делает | Сколько на «Четырёх краях» |
|---|---|---|
| `town` | город | 2 |
| `mine` | шахта с доходом | 14 |
| `pile` | кучка ресурсов | 24 |
| `guard` | охрана | 30 |
| `hero` (в поле `players`) | герой | 2 |

**Четыре вида объектов.** В Heroes 3 — около сорока.

## Чего нет: объекты, дающие героя сильнее

| Объект | Что даёт в Heroes 3 | Сколько стоит нам |
|---|---|---|
| **Арена** (`arena`) | +2 к характеристике | дёшево: одно правило |
| **Камень знаний** (`learningStone`) | +1000 опыта | дёшево |
| **Дерево знаний** (`treeOfKnowledge`) | уровень за золото | дёшево |
| **Школа магии** / **Школа войны** (`schoolOfMagic`, `schoolOfWar`) | +1 к характеристике | дёшево |
| **Фонтан молодости** (`fountainOfYouth`), **Оазис** (`oasis`), **Водопой** (`wateringHole`) | восстановление движения | дёшево |
| **Фонтан удачи**, **Идол удачи**, **Кольцо фей** | +удача, +дух | дёшево |
| **Лаборатория**, **Звёздная ось** | +мана, +характеристика | дёшево |
| **Шатёр** / **Мастерская** / **Палатка торговца** | покупка | средне |
| **Шахта с сокровищем** (`abandonedMine`) | шахта с охраной | дёшево |
| **Хижина ведьмы** (`witchHut`) | даёт навык | ждёт навыков |
| **Святилища магии** (`shrineOfMagicLevel1–3`) | заклинание за визит | ждёт объектов-заклинаний |
| **Свиток заклинания** (`spellScroll`) | одно заклинание | ждёт выучивания |
| **Хижина провидца** (`seerHut`) | квест за награду | ждёт системы квестов |

Первые десять строк — это «герой стал сильнее за визит». Все они опираются на одно правило (визит меняет характеристики героя) и дают непропорционально много: именно они превращают карту из «дойди до врага» в «обойди всё».

## Чего нет: объекты-препятствия и хитрости

| Объект | Что делает |
|---|---|
| **Стражи границы**, **Ключ и шатёр** (`borderGuard`, `keymasterTent`) | проход открывается ключом |
| **Гарнизон** (`garrison`) | чужие войска стоят в проходе навсегда |
| **Портал-монолит** (`monolith`) | переход в другую часть карты |
| **Водоворот** (`whirlpool`) | телепорт по воде |
| **Подземный ход** (`subterraneanGate`) | подземелье |
| **Квест-страж** (`questGuard`) | проход за выполненный квест |
| **События** (`event`), **Ящик Пандоры** (`pandoraBox`), **Тюрьма** (`prison`) | послание, награда, освобождение героя |
| **Обелиск** (`obelisk`) | части карты грааля |

## Чего нет: местность и движение

| Чего нет | Что это | Что даст |
|---|---|---|
| **Вода** | новая местность, непроходимая без корабля | три заклинания, верфь, водные объекты |
| **Корабли** | объект, на котором герой ходит по воде | то же |
| **Подземелье** | второй уровень карты и переходы | вдвое больше пространства |
| **Дороги** | ускоряют движение | уже есть в Heroes 3, у нас нет |
| **Плохая местность** | штраф к движению | навык «Поиск пути» |
| **Туман войны** | невидимое неразведанное | два заклинания обзора, интрига |
| **Границы карты** | проходимые и нет | — |

## Карты

| | У нас | В Heroes 3 |
|---|---|---|
| Настоящих карт | **1** («Четыре края», 36×36) | 100+ одиночных |
| Проверочных карт | 16 (для тестов, не для игры) | — |
| Размеры | 36×36 и проверочные | S/M/L/XL: 36×36, 72×72, 108×108, 144×144 |
| Кампаний | 0 | 7 кампаний по 8–20 карт |

Играбельная карта — не «ещё один файл»: на ней должны быть объекты, охранники, награды и развитие. Пока объектов четыре вида, любая новая карта будет похожа на «Четыре края». Поэтому порядок такой: объекты → карты.

## Что нужно решить владельцу

1. **Объекты-награды** — брать ли десять «герой стал сильнее» сразу? Они не меняют правил, кроме одного («визит меняет характеристики»), и это самое дешёвое оживление карты.
2. **Туман войны** — решение 0003 говорит «тумана нет». Оставить так или пересмотреть? Без него два заклинания обзора и «интрига исследования» недостижимы.
3. **Вода и корабли** — большая работа: местность, объект, движение, экран. Браться ли в этом проходе?
4. **Сколько карт** — 3–5 ручных или генератор случайных карт? Генератор дешевле в пересчёте на карту, но это отдельная программа.
