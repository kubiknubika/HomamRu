# Чего не хватает: каталог по предметам

Заказано владельцем 2026-11-11: «потратить время, чтобы написать всё, чего не достаёт, по предметно».

Это не roadmap и не спецификация правил. Это **перечень содержимого**: что в Heroes 3 есть, чего у нас нет, сколько именно, в каких файлах это будет жить и что нужно решить до кода. Числа Heroes 3 взяты не по памяти, а из первоисточника — конфигурации VCMI (`config/` в репозитории `vcmi/vcmi`), прочитанной 2026-11-11 через GitHub API. Где написано «наше» — это уже наши данные.

Догма 1 запрещает копировать оригинальные таблицы чисел целиком. Поэтому каталог делит всё на три вида:

| Вид | Что это | Кто делает |
|---|---|---|
| **Имена и состав** | сколько существ, замков, артефактов, навыков; по сколько уровней | не охраняется: состав механики |
| **Наши числа** | цены, атака, защита, урон — по нашей кривой, а не по таблице Heroes 3 | агент, по образцу уже сделанного |
| **Правила** | как артефакт надевается, что делает навык, как работает туман войны | **только по слову владельца** |

## В каком порядке это делать

Порядок — по отношению «сколько игры даёт» к «сколько стоит». Обоснование в каждом документе.

1. ~~**Пятый круг гильдии и три заклинания пятого круга**~~ — **сделано в порции 64**.
2. ~~**Существа седьмого уровня Чащи**~~ — **сделано в порции 64**: зубр (`aurochs`).
3. **Нейтральные существа** — 15 существ, которые делают охранников и карту живыми. Не требуют ни правил, ни новых экранов.
4. **Остальные семь замков** — по 14 существ и по ~15 жилищ каждый. Чистый контент, механика замка уже есть. Самый большой кусок и самый заметный.
5. **Двадцать навыков** — требуют правил (что каждый меняет), поэтому после слова владельца.
6. **Артефакты** — самая большая дырка и самая дорогая: нужна механика с нуля (слоты, надевание, потеря при гибели).
7. **Карты, объекты, туман войны, вода** — после контента: без существ и артефактов карту наполнять нечем.

## Что это меняет в процентах

Ось «контент» в `docs/scales.md` — среднее пяти долей. Посчитал, что даёт закрытие пунктов 1–4 (пятый круг, седьмой уровень Чащи, нейтралы, семь замков):

| Доля | Сейчас | После | Как считается |
|---|---|---|---|
| Существа | 14 из 122 = 11 % | 137 из 137 = **100 %** | 122 в замках + 15 нейтралов |
| Замки | 2 из 9 = 22 % | **100 %** | |
| Артефакты | 0 из 134 = 0 % | 0 % | не трогаем |
| Навыки | 8 из 28 = 29 % | 29 % | не трогаем |
| Заклинания | 54 из 70 = 77 % | 55 из 70 = **79 %** | «Убийца» ждёт зубра |
| **Ось контента** | 27,7 % | **61,4 %** | среднее |
| **Игра вообще** | 72 % | **82 %** | 0,30×99 + 0,30×61,4 + 0,15×75 + 0,15×95 + 0,10×85 = 82,1 |

То есть четыре пункта дают **+9 пунктов игры вообще**. Артефакты и навыки двигают меньше, чем кажется: их доли входят в ту же пятёрку, а стоит каждая дороже всех семи замков вместе.
