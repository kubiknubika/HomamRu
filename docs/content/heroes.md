# Герои: чего не хватает

У нас **6 героев** (`data/heroes.yaml`), у каждого атака, защита, сила магии и знание, все по 1–3. Классов нет, специализаций нет, портретов нет.

Числа Heroes 3 — VCMI `config/heroClasses.json` и `config/heroes/*.json` (2026-11-11).

## Классы героев

В Heroes 3 у каждого замка два класса — «военный» и «магический»:

| Замок | Военный класс | Магический класс |
|---|---|---|
| Люди | Рыцарь | Клирик |
| Чаща | Следопыт | Друид |
| Башня | Алхимик | Волшебник |
| Инферно | Демон | Еретик |
| Некрополь | Рыцарь смерти | Некромант |
| Подземелье | Владыка | Чернокнижник |
| Цитадель | Варвар | Боевой маг |
| Крепость | Укротитель | Ведьма |
| Согласие | Планарный | Элементалист |

**У нас 0 из 18.** Класс в Heroes 3 определяет две вещи: стартовые характеристики (рыцарь начинает с 2/2, клирик с 1/1 и большим знанием) и шансы, какие навыки ему предлагают. Второе — самая заметная часть: рыцарь почти не видит магию огня, а некромант её видит часто.

## Специализации

В Heroes 3 у каждого героя своя специализация: «+5 % к урону баллисты за уровень», «ополченцы нанимаются дешевле». Их 152 — по числу героев.

**У нас 0.** Это дёшево по правилам (обычно одна прибавка), но требует классов и, часто, артефактов.

## Чего ещё нет у героев

| Чего нет | В Heroes 3 | Что даст |
|---|---|---|
| **Уровни характеристик** | новый уровень даёт +1 к случайной характеристике и выбор навыка | у нас только выбор навыка |
| **Портреты** | у каждого героя | экран героя сейчас текстовый |
| **Биографии** | у каждого героя | текст в окне |
| **Герои по замкам** | 8–9 героев на замок, свой набор | у нас 6 на всё |
| **Начальные армии по классу** | зависят от класса | сейчас у всех одна |
| **Опыт: таблица уровней** | до 75-го уровня | у нас короткая таблица |

## Что нужно решить владельцу

1. **Классы** — брать ли их вместе с третьим замком? Это правило роста героя (какие навыки предлагают), без вашего слова не начинаю.
2. **Характеристика за уровень** — в Heroes 3 каждый уровень даёт +1 к случайной характеристике. У нас нет. Это меняет силу героя к концу партии заметно.
3. **Сколько героев** — по 2–3 на замок (6–9 всего) или полный набор по 8?
