# Вторичные навыки: чего не хватает

У нас **8 из 28**. Все восемь — магические школы и магия: `fire-magic`, `water-magic`, `earth-magic`, `air-magic`, `wisdom`, `mysticism`, `intelligence`, `sorcery` (`packages/core/src/skills.ts`).

Числа Heroes 3 — VCMI `config/skills.json` (2026-11-11). Там 28 навыков с индексами 0–27, у каждого три уровня: base, advanced, expert.

## Двадцать недостающих

Разделил на три группы: что можно делать сейчас, что ждёт контента, что меняет правила боя.

### Готовы к работе (не ждут ничего)

| Навык | Что делает | Уровни (базовый / продвинутый / экспертный) |
|---|---|---|
| **Логистика** (`logistics`) | запас хода на суше | +10 % / +20 % / +30 % |
| **Поиск пути** (`pathfinding`) | штраф за плохую местность | −25 % / −50 % / −100 % |
| **Разведка** (`scouting`) | радиус обзора | +1 / +2 / +3 |
| **Удача** (`luck`) | удача героя | +1 / +2 / +3 |
| **Боевой дух** (`leadership`) | дух отрядов | +1 / +2 / +3 |
| **Нападение** (`offence`) | урон в ближнем бою | +10 % / +20 % / +30 % |
| **Защита** (`armorer`) | уменьшение урона | −5 % / −10 % / −15 % |
| **Стрельба** (`archery`) | урон стрелков | +10 % / +25 % / +50 % |
| **Обучение** (`learning`) | опыт за бой | +5 % / +10 % / +15 % |
| **Поместья** (`estates`) | доход золотом в день | +125 / +250 / +500 |
| **Дипломатия** (`diplomacy`) | шанс, что нейтралы присоединятся | базовый / продвинутый / экспертный порог |
| **Орлиный глаз** (`eagleEye`) | шанс выучить заклинание из боя | 40 % / 50 % / 60 % |
| **Учёность** (`scholar`) | обмен заклинаниями между героями | 1 / 2 / 3 заклинания |
| **Тактика** (`tactics`) | расстановка перед боем | 3 / 5 / 7 клеток |
| **Баллистика** (`ballistics`) | выстрелы катапульты в осаде | 1 / 2 / 3 дополнительных |

Пятнадцать из них меняют только числа, которые у нас уже есть: движение, удача, дух, урон, доход, опыт, обзор. Их можно добавить, не трогая ни одной механики боя, — и это самая дешёвая часть.

### Ждут контента

| Навык | Чего ждёт |
|---|---|
| **Навигация** (`navigation`) | воды и кораблей: у нас нет местности «вода» |
| **Некромантия** (`necromancy`) | нежити и правила «поднять павших» |
| **Артиллерия** (`artillery`) | баллисты и палатки как боевых машин |
| **Первая помощь** (`firstAid`) | палатки |

### Меняют правила и потому ждут слова владельца

**Тактика** (расстановка перед боем), **дипломатия** (нейтралы присоединяются), **орлиный глаз** (заклинание из боя), **учёность** (передача заклинаний), **сопротивление** (`resistance`, шанс отбить чужое заклинание) — каждая добавляет новое действие в бой или на карту.

## Навык №28 — «Сопротивление»

Он в списке «меняет правила», потому что бросает кубик при каждом чужом заклинании: 5 % / 10 % / 20 % шанс, что оно не подействует. Это заметно меняет баланс магии, поэтому отдельно.

## Как навыки попадают к герою

Механика уже есть: новый уровень даёт выбор из двух навыков, у героя максимум 8 (`MAX_SKILLS`), уровни 1–3. Сейчас выбор идёт из восьми. Когда навыков станет 28, тот же код будет предлагать из 28 — правил менять не нужно.

**Важная деталь:** в Heroes 3 у каждого класса героя свой набор «родных» навыков и свои шансы. У нас классов нет, поэтому шансы одинаковые у всех. Если делать классы (`heroes.md`), шансы придётся добавить — это меняет то, как герой растёт.

3. **Классы героев** — нужны ли разные наборы навыков у разных героев, или пока все равны?
