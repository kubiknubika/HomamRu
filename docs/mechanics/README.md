# Спецификации механик

Здесь описаны правила игры: что происходит, по каким формулам и что бывает в крайних случаях. Код пишется по этим документам, а не наоборот (догма 3).

## Как читать статус

- **Черновик** — написан агентом, владелец ещё не подтвердил. Код по черновику не пишется.
- **Принято** — владелец подтвердил. По документу можно писать код.
