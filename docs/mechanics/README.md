# Спецификации механик

Здесь описаны правила игры: что происходит, по каким формулам и что бывает в крайних случаях. Код пишется по этим документам, а не наоборот (догма 3).

## Как читать статус

- **Черновик** — написан агентом, владелец ещё не подтвердил. Код по черновику не пишется.
- **Принято** — владелец подтвердил. По документу можно писать код.

## Отдельно: каталог того, чего не хватает

Спецификации в этой папке описывают **что уже решено**. Чего в игре ещё нет и сколько этого — в [`../content/`](../content/README.md): восемь документов по предметам (существа, замки, артефакты, навыки, заклинания, герои, карта и объекты, бой), с числами Heroes 3 из первоисточника (VCMI) и с причиной нехватки у каждого пункта. Спецификация пишется, когда владелец выбрал предмет; каталог нужен, чтобы было из чего выбирать.
