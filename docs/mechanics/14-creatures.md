# Существа

Статус: принято владельцем 2026-11-12. Этап 2.

Три существа первой версии (решение 0003): пехотинец, стрелок и летун. Названия и числа свои; ни одна строка не повторяет существо из игр серии.

| | Ополченец | Пращник | Сокол |
|---|---|---|---|
| Идентификатор | `militia` | `slinger` | `falcon` |
| Роль | пехотинец | стрелок | летун |
| Атака | 5 | 5 | 7 |
| Защита | 5 | 3 | 5 |
| Урон | 2–3 | 1–4 | 3–5 |
| Здоровье | 12 | 9 | 18 |
| Скорость | 4 | 5 | 8 |
| Летает | нет | нет | да |
| Стреляет | нет | да | нет |
| Выстрелов | — | 10 | — |

Замысел:

- **Ополченец** — дешёвая стойкая пехота. Медленный: до врага идёт три-четыре хода.
- **Пращник** — стрелок. Хрупкий; вблизи бьёт вполсилы. Разброс урона большой.
- **Сокол** — боевая птица. Быстрый: за один-два хода долетает до вражеских стрелков и мешает им стрелять.

Цена, прирост и жилища — этап 4.

Числа — первое приближение. Они будут уточняться по автобоям (шаг 2.2); каждое изменение — через этот документ.

## Файл существа

Существа лежат в `data/creatures/`, по одному файлу JSON на существо (решение 0002).

```json
{
  "id": "slinger",
  "name": "Пращник",
  "attack": 5,
  "defense": 3,
  "damageMin": 1,
  "damageMax": 4,
  "health": 9,
  "speed": 5,
  "flying": false,
  "shots": 10
}
```

`shots` равно 0 у существ, которые не стреляют.

Ошибки в файле: пустое название; атака или защита меньше 0; урон «от» меньше 1 или больше урона «до»; здоровье меньше 1; скорость меньше 1; выстрелов меньше 0.

## Картинки

Каждое существо рисуется заглушкой: фигура с первой буквой названия и числом существ в отряде (догма 14). Картинка подставляется по идентификатору, когда появится в `packages/client/public/assets/creatures/`.
