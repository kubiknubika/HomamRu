# Действия в бою

Статус: черновик. Этап 2.

## Перемещение

Скорость существа — сколько клеток отряд проходит за ход.

**Пеший отряд** идёт по соседним клеткам. Каждая клетка пути должна быть свободна: без препятствия и без другого отряда, своего или чужого. Длина пути — не больше скорости.

**Летающий отряд** перелетает на любую свободную клетку, расстояние до которой не больше скорости. Что лежит по дороге, неважно.

Отряд не может «переместиться» на клетку, где уже стоит.

В команде указана только клетка назначения. Путь пешего отряда ядро находит само; если путей несколько, на результат это не влияет.

## Удар в ближнем бою

Ударить можно врага, стоящего в соседней клетке.

Отряд может сначала переместиться, а потом ударить — это одно действие. В команде указаны цель и клетка, с которой наносится удар. Эта клетка должна быть соседней с целью и либо той, где отряд стоит, либо той, куда он может переместиться.

Порядок:

1. Отряд перемещается на клетку удара, если он не на ней.
2. Отряд наносит урон (см. `13-battle-damage.md`).
3. Если в отряде-цели остались живые и он в этом раунде ещё не отвечал — он наносит ответный удар.

## Ответный удар

- Отряд отвечает один раз за раунд — на первый удар в ближнем бою.
- Отвечают только выжившие: урон считается по числу существ после полученного удара.
- На ответный удар не отвечают.
- На выстрел не отвечают.
- Защищающийся и ждущий отряды отвечают как обычно.

## Выстрел

Стрелять может существо-стрелок, если выполнено всё сразу:

1. У отряда остались выстрелы.
2. Ни в одной соседней клетке нет врага.

Цель — любой вражеский отряд на поле. Перемещаться перед выстрелом нельзя.

- Выстрел тратит один выстрел из запаса отряда. Запас задан существу и не зависит от числа существ в отряде.
- Если расстояние до цели больше 10, урон вдвое меньше.
- Ответа на выстрел нет.

Стрелок, рядом с которым стоит враг или у которого кончились выстрелы, может бить в ближнем бою. Урон стрелка в ближнем бою вдвое меньше. Это относится и к его ответному удару.

## Команды боя

| Команда | Что указано |
|---|---|
| Переместиться | клетка назначения |
| Ударить | отряд-цель и клетка, с которой наносится удар |
| Выстрелить | отряд-цель |
| Ждать | — |
| Защищаться | — |
| Бежать | — |

У каждой команды есть сторона, которая её отдала. Команда всегда относится к отряду, чей сейчас ход: выбрать другой отряд нельзя.

Команда применяется целиком или не применяется совсем (как в `00-state-and-commands.md`).

## Причины отказа

| Код | Когда |
|---|---|
| `BATTLE_OVER` | бой уже закончен |
| `NOT_YOUR_STACK` | сейчас ход отряда другой стороны |
| `CELL_UNREACHABLE` | клетка вне поля, занята, с препятствием, слишком далеко или это клетка самого отряда (для перемещения) |
| `UNKNOWN_TARGET` | отряда-цели нет или он погиб |
| `TARGET_IS_ALLY` | цель — свой отряд |
| `NOT_ADJACENT` | клетка удара не соседняя с целью |
| `NOT_A_SHOOTER` | существо не стрелок |
| `NO_SHOTS` | выстрелы кончились |
| `ENEMY_ADJACENT` | рядом со стрелком враг |
| `ALREADY_WAITED` | отряд уже ждал в этом раунде |
| `NO_HERO` | бежать некому: у стороны нет героя |

Если причин несколько, называется первая по порядку этой таблицы. Для удара клетка проверяется после цели: сначала `UNKNOWN_TARGET`, `TARGET_IS_ALLY`, `NOT_ADJACENT`, затем `CELL_UNREACHABLE`.

## События боя

| Событие | Что в нём |
|---|---|
| раунд начался | номер раунда |
| ход отряда | отряд |
| отряд оцепенел | отряд |
| отряд переместился | отряд, откуда, куда |
| удар | кто, кого, вид (удар, ответный удар, выстрел), урон, убито, осталось, была ли удача |
| отряд погиб | отряд |
| отряд ждёт | отряд |
| отряд защищается | отряд, прибавка к защите |
| боевой дух: второй ход | отряд |
| сторона бежала | сторона |
| бой окончен | победитель, причина, потери |

## Порядок случайных бросков

Чтобы повтор боя давал тот же результат, броски идут в строго заданном порядке:

1. В начале хода, при низком боевом духе: жребий оцепенения.
2. При ударе или выстреле: сначала жребий удачи (если удача больше нуля), затем броски урона по одному на существо, но не больше десяти.
3. При ответном ударе — то же для отвечающего.
4. После действия, при высоком боевом духе: жребий второго хода.

Если жребий не нужен (боевой дух или удача равны нулю), случайное число не берётся.

## Крайние случаи

- Отряд окружён и не может ни пойти, ни ударить, ни выстрелить: ему остаются «ждать» и «защищаться». Эти две команды доступны всегда.
- Удар без перемещения возможен, даже если все остальные клетки вокруг заняты.
- Летающий отряд не может ударить врага, вокруг которого нет ни одной свободной клетки в пределах досягаемости.
- Цель погибла от удара: ответа нет.
- Нападавший погиб от ответного удара: жребий второго хода не бросается.

## Свойства, верные всегда

- После принятой команды перемещения отряд стоит в указанной клетке; расстояние от прежней клетки не больше скорости.
- Число существ в отряде и запас выстрелов никогда не растут.
- За раунд отряд наносит не больше одного ответного удара.
- Отклонённая команда не меняет состояние боя и не тратит случайных чисел.
