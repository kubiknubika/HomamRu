# Карта приключений

Статус: принято владельцем 2026-11-11. Этап 1.

## Сетка

- Карта — прямоугольник из квадратных клеток.
- У клетки есть координаты `x` (слева направо) и `y` (сверху вниз). Левая верхняя клетка — `x = 0, y = 0`.
- Размер карты: от 8×8 до 144×144 клеток.

## Местность

На этапе 1 местность двух видов:

| Вид | Символ в файле | Можно ходить |
|---|---|---|
| земля | `.` | да |
| преграда | `#` | нет |

Штрафов за местность и дорог нет (решение 0003).

## Что стоит на карте

На этапе 1 на карте стоят только герои. Ресурсы, шахты, охранники и города появятся на следующих этапах.

- В одной клетке может стоять не больше одного героя.
- Герой стоит только на земле.

## Файл карты

Карта описывается файлом YAML. Местность рисуется строками символов, поэтому карту можно читать и править глазами.

```yaml
id: test-small
name: Маленькая проверочная карта
terrain:
  - "........"
  - "..##...."
  - "..#....."
  - "........"
  - "....##.."
  - "........"
  - "........"
  - "........"
players:
  - hero: { x: 1, y: 1 }
```

| Поле | Что это |
|---|---|
| `id` | идентификатор карты: латиница, строчные буквы, цифры, дефис |
| `name` | название для игрока |
| `terrain` | строки карты сверху вниз; каждый символ — одна клетка |
| `players` | игроки по порядку хода; у каждого — начальная клетка героя |

## Проверка карты

Карта отвергается с понятным сообщением, если:

- строки местности разной длины;
- размер меньше 8×8 или больше 144×144;
- встретился неизвестный символ;
- игроков меньше одного или больше двух;
- герой стоит вне карты или на преграде;
- два героя стоят в одной клетке.

Сообщение называет файл и место: номер строки и столбца или поле.

## Карты этапа 1

- **Маленькая проверочная карта** — для ручной проверки и сценариев.
- **Большая нагрузочная карта** 72×72 — только для проверки скорости на телефоне. Она вдвое больше по каждой стороне, чем нужно первой версии.

Настоящая карта первой играбельной версии появится на этапе 3, вместе с объектами.

## Крайние случаи

- Карта, на которой герою некуда идти (он окружён преградами), допустима: герой просто не может ходить.
- Клетки по краю карты ничем не отличаются от остальных; выйти за край нельзя.
