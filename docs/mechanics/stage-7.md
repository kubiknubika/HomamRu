# Этап 7. Магия

Статус: **план принят владельцем 2026-11-14** (объём, порядок шагов, названия). Шаг 7.1 сделан в коде; его спецификации `61-magic.md` и `62-battle-spells.md` ждут приёмки. Числа сверены с таблицами самой Heroes 3 и с кодом VCMI.

## Что должно получиться

Магия Heroes 3 целиком (слово владельца: «полный перенос из героев всего»): 70 заклинаний, гильдия магов в пять уровней, четыре школы, мана, книга, магические навыки героя, заклинания в бою и на карте, компьютер, который колдует.

Пример. У героя сила магии 2 и знание 2 — это 20 маны. «Волшебная стрела» стоит 5 маны и наносит `10 × 2 + 10 = 30` урона: два ополченца из сорока убиты, третий ранен. Маны хватит на четыре стрелы; за ночь вне города вернётся 1 мана, в городе с гильдией — вся.

## Документы этапа

| Документ | О чём |
|---|---|
| `60-spells.md` | все 70 заклинаний: круг, школа, цена, числа |
| `61-magic.md` | сила магии и знание, мана, гильдия магов, книга, выучивание |
| `62-battle-spells.md` | колдовство в бою и двенадцать заклинаний первого круга |

Экран, навыки, заклинания старших кругов и карты — отдельными документами перед своим шагом.

## Решения владельца (2026-11-14)

| Вопрос | Решение |
|---|---|
| Объём | полный перенос магии Heroes 3, а не шесть заклинаний |
| Числа, записанные по памяти | проверить — проверено, см. «Сверка» |
| Сила магии и знание героев | у каждого героя по 1; за уровень +1 к одной из четырёх характеристик поровну. Записать в «Исправить»: после появления классов героев сделать как в Heroes 3 |
| Книга заклинаний | покупается |
| Набор заклинаний в гильдии | случайный |
| Охранники, башни и магия | как в Heroes 3 |

«Как в Heroes 3» для охранников и башен значит: охранник без героя не колдует; башни и стены целью заклинаний не бывают (кроме «Землетрясения»); существа сопротивляются магии только своими особыми способностями, а таких способностей у наших четырёх существ нет.

## Чего в игре не хватает для полного переноса

Магия Heroes 3 опирается на вещи, которых у нас нет. Каждая — отдельная работа.

| Чего нет | Что без этого не работает |
|---|---|
| Вторичные навыки героя | школы магии (без навыка заклинание действует в слабейшем виде и стоит дороже), «Мудрость» (без неё герой учит только круги 1 и 2), «Волшебство», «Интеллект», «Мистицизм», «Сопротивление», «Зоркость», «Грамотность» |
| Четыре редких ресурса: ртуть, сера, кристаллы, самоцветы | гильдии уровней 2–5 стоят по 4, 6, 8 и 10 единиц каждого |
| Нежить, элементали, существа седьмого уровня | 8 заклинаний |
| Вода и корабли, туман войны | 5 заклинаний карты |
| Особые способности существ | иммунитеты и сопротивление магии, существа-колдуны |
| Отряды на две клетки | часть правил «Телепорта», «Силового поля», заклинаний по площади |
| Артефакты | «Молния титана», прибавки к силе магии и знанию |

## Шаги

Порядок такой, чтобы после каждого шага в игру можно было играть.

| Шаг | Что делается | Как проверяется |
|---|---|---|
| 7.1. Основа | сила магии и знание; мана; книга; гильдия магов первого уровня со случайным набором; колдовство в бою; все боевые заклинания первого круга, 12 штук; сохранение | автоматически: тесты, сценарии |
| 7.2. Компьютер и экран | компьютер строит гильдию, покупает книгу и колдует; книга заклинаний на экране боя, мана, значки действий на отрядах, гильдия в городе | сводки боёв и партий; владелец в браузере |
| 7.3. Навыки героя | вторичные навыки: выбор при повышении уровня, восемь магических навыков; уровни школ в заклинаниях | автоматически |
| 7.4. Редкие ресурсы и гильдия до пятого уровня | четыре ресурса, их шахты и кучки, гильдии 2–5 | автоматически |
| 7.5. Боевые заклинания кругов 2–5 | оставшиеся 48, группами: урон по площади, действия на отряд, препятствия на поле, управление чужим отрядом, воскрешение и вызов | автоматически; владелец в браузере |
| 7.6. Заклинания карты | «Городской портал», «Дверь измерений», «Полёт», «Видения», «Маскировка» | автоматически; владелец в браузере |
| 7.7. Карта и телефон | числа «Четырёх краёв» с магией | владелец на телефоне |

Заклинания, которым не хватает существ, воды или тумана (13 штук, список в `60-spells.md`), появятся вместе с тем, чего им не хватает; до тех пор в гильдии их нет.

## Сверка с Heroes 3

Источники: таблицы самой игры `SPTRAITS.TXT` (заклинания) и `BUILDING.TXT` (цены зданий), найденные на GitHub как справочные файлы (первый — `ethernidee/advanced-classes-mod` и `pikipiki/heroes3-goonks-and-magic`, совпали байт в байт; второй — `CalZing/HeroesIIISwedish`, `text/original`); код VCMI (github.com/vcmi/vcmi, состояние на 2026-11-14).

| Правило | Что в источнике | Итог |
|---|---|---|
| Цена, круг, школа, сила и числа каждого заклинания | `SPTRAITS.TXT` | сверено; числа первого черновика «по памяти» подтвердились |
| Урон = сила заклинания × сила магии героя + прибавка уровня навыка | VCMI, `lib/spells/CSpellHandler.cpp`: `calculateRawEffectValue` | сверено |
| Гильдия магов: 2000 золота, 5 дерева, 5 руды; уровни 2–5 — по 1000 золота, 5 дерева, 5 руды и по 4, 6, 8, 10 каждого редкого ресурса | `BUILDING.TXT`, «Neutral Buildings» | сверено |
| В гильдии уровня N — `6 − N` заклинаний круга N: 5, 4, 3, 2, 1 | VCMI, `lib/mapObjects/CGTownInstance.cpp`: `spellsAtLevel` | сверено |
| Без «Мудрости» герой учит только круги 1 и 2 | VCMI, `config/gameConfig.json`: `MAX_LEARNABLE_SPELL_LEVEL`; `config/skills.json` | сверено |
| Мана = знание × 10 | VCMI, `config/gameConfig.json`: `manaPerKnowledge`, 1000 % | сверено |
| +1 маны в день; герой, начавший день в городе с гильдией, получает всю ману | VCMI, `lib/mapObjects/CGHeroInstance.cpp`: `getManaNewTurn` | сверено |
| Книга стоит 500 золота | VCMI, `lib/constants/NumericConstants.h`: `SPELLBOOK_GOLD_COST` | сверено |
| Без книги колдовать нельзя; одно заклинание в раунд | VCMI, `lib/constants/Enumerations.h`: `NO_SPELLBOOK`, `CASTS_PER_TURN_LIMIT` | сверено |
| Срок действия = сила магии героя, в раундах | VCMI, `lib/spells/ISpellMechanics.cpp` | сверено |
| «Проклятие» снимает «Благословение», «Замедление» — «Ускорение», и наоборот | VCMI, `config/spells/timed.json`: `counters` | сверено |
| С какой вероятностью заклинание попадает в гильдию | `SPTRAITS.TXT`: своё число для каждого из девяти городов Heroes 3 | взяты числа замка людей (слово владельца) |
| «Замедление»: (скорость + прибавки) × 75 %, дробь отбрасывается | VCMI, `config/spells/timed.json` (`STACKS_SPEED`, −25, `PERCENT_TO_ALL`), `lib/bonuses/BonusList.cpp`: `applyPercentageRoundDown` | сверено |
| Набор гильдии: по кругам, жребий по шансам, без повторов; шанс 0 не выпадает; обязательных заклинаний нет | VCMI, `lib/gameState/CGameState.cpp`: раздача заклинаний городам | сверено |
| «Щит» 85 %, защита от школы 70 %, «Каменная кожа» и «Жажда крови» +3, «Ускорение» +3 | `SPTRAITS.TXT`; виды действий — VCMI, `config/spells/timed.json` | сверено |
| Поведение самой Heroes 3 там, где VCMI мог отойти от неё | проверить нечем | не сверено |
