# Город

Статус: черновик агента, ждёт согласия владельца. Этап 4.

## Город на карте

- Город — объект карты, занимает одну клетку земли. У него есть владелец — игрок.
- Герой владельца входит в город, встав на его клетку (как на шахту). Пока герой стоит на клетке города, он «в городе».
- Чужих и ничьих городов на этапе 4 нет: карта с таким городом отвергается. Захват города — этап 5.
- У каждого игрока не больше одного города.
- Город может стоять в зоне охранника: тогда, как и с шахтой, вход в него — это бой.

## Файл карты

```yaml
players:
  - hero: { x: 2, y: 2, army: [{ creature: militia, count: 15 }] }
    resources: { gold: 20000, wood: 20, ore: 20 }
objects:
  - { type: town, x: 3, y: 3, owner: 0, buildings: [militia-yard] }
```

| Поле | Что это |
|---|---|
| `owner` | номер игрока, с нуля |
| `buildings` | что построено в начале; можно не писать — тогда ничего |
| `garrison` | гарнизон в начале, как `army` у героя; можно не писать — тогда пусто |

Карта отвергается, если: владельца нет среди игроков; у игрока два города; здание неизвестно или записано дважды; построено здание без того, что ему нужно; в гарнизоне неизвестное существо, число меньше 1 или один вид существ дважды.

## Здания

Здания описаны в файле данных `data/buildings.yaml` (догма 8).

| Здание | Идентификатор | Цена | Что нужно | Что даёт |
|---|---|---|---|---|
| Ратуша | `town-hall` | 2500 золота | — | доход города 1000 золота в день вместо 500 |
| Форт | `fort` | 5000 золота, 20 дерева, 20 руды | — | прирост во всех жилищах больше наполовину |
| Двор ополченцев | `militia-yard` | 500 золота, 10 руды | — | прирост ополченцев |
| Стрельбище пращников | `slinger-range` | 1000 золота, 5 дерева, 5 руды | двор ополченцев | прирост пращников |
| Соколиная башня | `falcon-tower` | 1000 золота, 5 руды | стрельбище пращников | прирост соколов |

Улучшений зданий нет. Снести здание нельзя.

## Строительство

Команда `build { player, townId, building }`.

- В каждом городе — одно здание в день. Счёт обнуляется в начале дня игрока.
- Герой для строительства не нужен.
- Цена списывается сразу, здание готово сразу.

Команда отклоняется:

| Причина | Код |
|---|---|
| города нет или он чужой | `NO_TOWN` |
| здания с таким идентификатором нет | `UNKNOWN_BUILDING` |
| уже построено | `ALREADY_BUILT` |
| сегодня в этом городе уже строили | `BUILT_TODAY` |
| не построено то, что нужно | `REQUIREMENT_MISSING` |
| не хватает ресурсов | `NOT_ENOUGH_RESOURCES` |
| идёт бой | `BATTLE_IN_PROGRESS` |
| партия окончена | `GAME_OVER` |

Проверки идут в этом порядке, после общих проверок команды.

Событие: `buildingBuilt { townId, building, cost }`.

## Доход

В начале каждого дня, начиная со второго, город приносит владельцу золото: 500, а с ратушей 1000. Доход приходит вместе с доходом шахт, одним событием `incomeReceived`.

| День | Ратуша | Шахты игрока | Доход |
|---|---|---|---|
| 1 | нет | нет | ничего: в первый день дохода нет |
| 2 | нет | нет | 500 золота |
| 2 | есть | нет | 1000 золота |
| 2 | есть | золотая шахта, лесопилка | 2000 золота, 2 дерева |
| 2 | построена в день 2 | нет | 500 золота: доход считается в начале дня, до строительства |

## Состояние

У города: идентификатор, клетка, владелец, список построенных зданий, строили ли сегодня, сколько существ каждого вида ждёт найма, гарнизон.

## Свойства, верные всегда

- Ресурсы игрока не бывают отрицательными.
- Здание в списке построенных встречается один раз, и всё, что ему нужно, тоже построено.
- За день в городе построено не больше одного здания.
- Отклонённая команда ничего не меняет.

## Текстовый вывод

Город печатается после объектов:

```
Город o5 (3, 3), игрок 1: ратуша, двор ополченцев. Сегодня строили: нет.
  Ждут найма: ополченец 14.
  Гарнизон: пусто.
```

На карте город — буква `T`.
