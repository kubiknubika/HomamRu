# Перемещение героя

Статус: черновик. Этап 1.

Числа в таблицах посчитаны скриптом `examples/movement.py`, а не кодом игры.

## Запас хода

- У героя есть запас хода на день: **1000 очков**.
- Запас восстанавливается полностью в начале каждого дня. Неизрасходованный остаток сгорает.
- На этапе 1 запас одинаков для всех героев и не зависит от армии.

## Шаг

Герой ходит по клеткам в восьми направлениях: прямо и по диагонали.

| Шаг | Стоимость |
|---|---|
| прямо (вверх, вниз, влево, вправо) | 100 |
| по диагонали | 141 |

Шаг возможен, если выполнено всё сразу:

1. Клетка назначения находится на карте.
2. В ней земля, а не преграда.
3. В ней не стоит другой герой.
4. У героя осталось очков не меньше стоимости шага.
5. Для шага по диагонали: хотя бы одна из двух клеток, между которыми он проходит, — не преграда.

Правило 5 запрещает протискиваться в щель между двумя преградами, которые касаются углами. Срезать угол одной преграды можно.

Если очков меньше стоимости шага, шаг невозможен, даже если не хватает одного очка.

## Примеры: запас хода

| Что сделал герой за день | Потрачено | Осталось | Ещё шаг прямо | Ещё шаг по диагонали |
|---|---|---|---|---|
| 3 шага прямо | 300 | 700 | да | да |
| 3 шага по диагонали | 423 | 577 | да | да |
| 9 шагов прямо | 900 | 100 | да | нет |
| 10 шагов прямо | 1000 | 0 | нет | нет |
| 7 шагов по диагонали | 987 | 13 | нет | нет |
| 4 прямо и 4 по диагонали | 964 | 36 | нет | нет |

За день герой проходит не больше 10 клеток прямо или 7 по диагонали.

## Команда «переместить героя»

В команде указаны герой и путь — список шагов по порядку. Путь выбирает тот, кто отдаёт команду; ядро его только проверяет.

Команда принимается, если каждый шаг пути возможен в тот момент, когда до него дошла очередь. Тогда герой проходит весь путь.

Если хотя бы один шаг невозможен, команда отклоняется целиком и герой остаётся на месте.

Причины отказа:

| Код | Когда |
|---|---|
| `UNKNOWN_HERO` | героя с таким идентификатором нет |
| `NOT_OWNER` | герой принадлежит другому игроку |
| `EMPTY_PATH` | в пути нет ни одного шага |
| `STEP_BLOCKED` | шаг ведёт за край карты, на преграду, на другого героя или в щель между преградами |
| `NOT_ENOUGH_MOVEMENT` | на какой-то шаг не хватает очков |

В сообщении об отказе указан номер шага, на котором путь оборвался.

События принятой команды: по одному событию «герой сделал шаг» на каждый шаг — откуда, куда, сколько потрачено, сколько осталось.

## Поиск пути

Поиск пути — запрос: он ничего не меняет. Им пользуются интерфейс и компьютерный противник.

- Ищется путь с наименьшей суммарной стоимостью.
- Если самых дешёвых путей несколько, выбирается тот, у которого раньше встречается направление, стоящее раньше в списке: вверх, вверх-вправо, вправо, вниз-вправо, вниз, вниз-влево, влево, вверх-влево. Сравнение идёт по первому шагу, при равенстве — по второму, и так далее.
- Запас хода при поиске не учитывается: путь может быть длиннее, чем герой пройдёт за день.
- Другой герой на пути считается преградой.
- Если пути нет, запрос отвечает «пути нет». Это не ошибка.

Второе правило нужно, чтобы один и тот же запрос всегда давал один и тот же путь на любом устройстве.

Запрос также сообщает, сколько дней займёт путь и какую его часть герой пройдёт сегодня.

## Сколько дней занимает путь

Герой идёт по пути, пока хватает очков. Если на следующий шаг очков не хватает, день заканчивается, остаток сгорает, и шаг делается на следующий день с полным запасом.

## Примеры: пути

Обозначения: `S` — герой, `T` — цель, `#` — преграда, `.` — земля. Направления: С — вверх, Ю — вниз, В — вправо, З — влево.

**A. Открытое поле**

```
.......
.S.....
.......
.....T.
.......
```

Путь: В, В, ЮВ, ЮВ. Шагов 4, стоимость 482, один день, остаётся 518.

**B. Стена с проходом снизу**

```
...#...
.S.#.T.
...#...
.......
```

Путь: ЮВ, ЮВ, СВ, СВ. Шагов 4, стоимость 564, один день, остаётся 436.

**C. Щель между преградами закрыта**

```
S#...
#T...
.....
```

Пути нет: шаг по диагонали прошёл бы между двумя преградами.

**D. Угол одной преграды можно срезать**

```
S#...
.T...
.....
```

Путь: ЮВ. Стоимость 141, остаётся 859.

**E. Цель отрезана стеной**

```
S.#..
..#.T
..#..
```

Пути нет.

**F. Прямая диагональ**

```
S..
...
..T
```

Путь: ЮВ, ЮВ. Стоимость 282, остаётся 718.

**G. Несколько самых дешёвых путей**

```
S...
...T
```

Три пути стоят одинаково, по 341: «В, В, ЮВ», «В, ЮВ, В» и «ЮВ, В, В». Выбирается «В, В, ЮВ»: направление «вправо» стоит в списке раньше, чем «вниз-вправо».

**H. Путь на несколько дней**

```
S.............
############..
T.............
```

Путь: 11 раз В, затем ЮВ, ЮЗ, затем 11 раз З. Шагов 24, стоимость 2482.

- День 1: 10 шагов вправо, потрачено 1000.
- День 2: шаг вправо, два шага по диагонали, 6 шагов влево, потрачено 982. Остаётся 18, на шаг не хватает, остаток сгорает.
- День 3: 5 шагов влево, потрачено 500, остаётся 500.

Итого 3 дня.

## Свойства, верные всегда

Эти правила проверяются автоматически на случайных картах:

- Найденный путь всегда принимается командой, если у героя хватает очков.
- Стоимость найденного пути не больше стоимости любого другого пути между теми же клетками.
- Остаток запаса хода никогда не становится отрицательным.
- После принятой команды герой стоит в последней клетке пути, а потрачено ровно столько, сколько стоит путь.
- После отклонённой команды состояние не изменилось.
- Путь из клетки в неё саму — пустой; команда с пустым путём отклоняется.

## Крайние случаи

- Путь может проходить через одну клетку дважды. Это не запрещено, просто дороже.
- Герой, окружённый преградами, никуда пойти не может; любая команда перемещения отклоняется.
- Самый дешёвый путь не всегда самый быстрый по дням: из-за сгорающего остатка более дорогой путь иногда укладывается в меньшее число дней. Поиск это не учитывает и всегда выбирает самый дешёвый.

## Как игрок управляет героем

Это описание интерфейса, а не правило ядра.

- Первое касание клетки показывает путь до неё: часть, которую герой пройдёт сегодня, и часть на следующие дни — разным цветом.
- Второе касание той же клетки отправляет героя. Он проходит столько шагов пути, на сколько хватает очков.
- Касание другой клетки показывает новый путь.
- Если пути нет, клетка помечается как недостижимая.
