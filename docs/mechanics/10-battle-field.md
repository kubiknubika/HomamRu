# Поле боя

Статус: черновик. Этап 2.

Числа в таблицах посчитаны скриптом `examples/battle.py`, а не кодом игры.

## Поле

- Поле — 15 клеток в ширину и 11 в высоту. Клетки шестиугольные.
- Клетка задаётся парой (столбец, ряд). Столбцы — от 0 до 14 слева направо, ряды — от 0 до 10 сверху вниз.
- Ряды с нечётным номером сдвинуты вправо на полклетки.

```
ряд 0:  00  10  20  30 ...
ряд 1:    01  11  21  31 ...
ряд 2:  02  12  22  32 ...
```

- Нападающий стоит слева, обороняющийся — справа.

## Соседи

У клетки до шести соседей: слева, справа, двое сверху и двое снизу.

- В чётном ряду верхние и нижние соседи — в столбцах «тот же» и «на один левее».
- В нечётном ряду — в столбцах «тот же» и «на один правее».

| Клетка | Соседей | Соседи |
|---|---|---|
| (3, 4) | 6 | (2, 3), (2, 4), (2, 5), (3, 3), (3, 5), (4, 4) |
| (3, 5) | 6 | (2, 5), (3, 4), (3, 6), (4, 4), (4, 5), (4, 6) |
| (0, 0) | 2 | (0, 1), (1, 0) |
| (14, 10) | 3 | (13, 9), (13, 10), (14, 9) |
| (0, 5) | 5 | (0, 4), (0, 6), (1, 4), (1, 5), (1, 6) |
| (14, 5) | 3 | (13, 5), (14, 4), (14, 6) |

## Расстояние

Расстояние между клетками — наименьшее число шагов по соседним клеткам на пустом поле. Препятствия и отряды на него не влияют.

| От | До | Расстояние |
|---|---|---|
| (0, 0) | (14, 0) | 14 |
| (0, 0) | (0, 10) | 10 |
| (0, 0) | (14, 10) | 19 |
| (0, 5) | (14, 5) | 14 |
| (3, 4) | (4, 5) | 2 |
| (3, 5) | (4, 6) | 1 |
| (3, 5) | (3, 6) | 1 |
| (2, 3) | (7, 8) | 7 |
| (0, 5) | (10, 5) | 10 |
| (0, 5) | (11, 5) | 11 |
| (0, 0) | (9, 10) | 14 |

## Армия и отряд

- Армия — от 1 до 7 отрядов. Порядок отрядов в армии важен: от него зависит расстановка.
- Отряд — вид существа и их число, не меньше 1. Все существа отряда занимают одну клетку.
- Одинаковые существа могут стоять в разных отрядах.
- У армии может быть герой. Он на поле не стоит. Его атака и защита прибавляются к атаке и защите каждого его отряда.
- У армии есть боевой дух (от −3 до +3) и удача (от 0 до +3), общие для всех её отрядов. На этапе 2 их задаёт файл боя; откуда они берутся в партии — этапы 3 и 4.

## Расстановка

Нападающий занимает столбец 0, обороняющийся — столбец 14. Ряд зависит от числа отрядов в армии:

| Отрядов | Ряды по порядку отрядов |
|---|---|
| 1 | 5 |
| 2 | 2, 8 |
| 3 | 2, 5, 8 |
| 4 | 0, 4, 6, 10 |
| 5 | 0, 2, 5, 8, 10 |
| 6 | 0, 2, 4, 6, 8, 10 |
| 7 | 0, 2, 4, 5, 6, 8, 10 |

## Препятствия

- Препятствие занимает одну клетку. Список клеток с препятствиями задаёт файл боя.
- На клетку с препятствием нельзя встать. Пешие существа обходят её, летающие перелетают.
- Стрельбе препятствия не мешают.
- Препятствий не бывает в столбцах 0 и 14.

## Файл боя

Проверочные бои лежат в `data/battles/`, по одному файлу YAML на бой.

```yaml
id: test-basic
name: Проверочный бой
obstacles: [[6, 3], [7, 5], [8, 7]]
attacker:
  hero: { attack: 1, defense: 1 }
  morale: 1
  luck: 0
  army:
    - { creature: militia, count: 20 }
    - { creature: slinger, count: 12 }
    - { creature: falcon, count: 5 }
defender:
  morale: 0
  luck: 0
  army:
    - { creature: militia, count: 30 }
    - { creature: slinger, count: 8 }
```

- `hero` можно не указывать: тогда у армии героя нет.
- Характеристики существ лежат отдельно: `data/creatures/` (см. `14-creatures.md`).

Причины, по которым бой не создаётся: неизвестное существо; отрядов нет или больше 7; число существ меньше 1; боевой дух или удача вне пределов; препятствие вне поля, в столбце 0 или 14, или дважды в одной клетке.

## Свойства, верные всегда

- В одной клетке не больше одного отряда.
- Отряд никогда не стоит на препятствии и вне поля.
- Расстояние от A до B равно расстоянию от B до A; расстояние между соседями равно 1.
