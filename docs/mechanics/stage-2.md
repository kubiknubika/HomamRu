# Этап 2. Бой

Статус: принято владельцем 2026-11-12.

Основание — решение 0003, раздел «Бой».

## Что должно получиться

Бой на шестиугольном поле между двумя армиями. Он запускается отдельно от карты: из меню, с готовыми армиями. Бой можно выиграть и проиграть. За противника ходит простой компьютер.

Связи с картой на этом этапе нет: нападения на охранников, опыт героя и потери армии после боя — этап 3.

Названия и характеристики существ — свои (догма 1).

## Сверка с Heroes 3

Владелец попросил правила не выдумывать, а взять из Heroes 3. Агент сверил черновик с источниками 2026-11-12.

| Правило | Что в источнике | Итог сверки |
|---|---|---|
| Поле | 11 рядов по 15 шестиугольников | совпало |
| Какие ряды сдвинуты | чётные (верхний ряд сдвинут вправо) | **в черновике было наоборот, исправлено** |
| Расстановка отрядов | ряды 5 / 2, 8 / 2, 5, 8 / 0, 4, 6, 10 / 0, 2, 5, 8, 10 / 0, 2, 4, 6, 8, 10 / 0, 2, 4, 5, 6, 8, 10 | совпало |
| Базовый урон | до 10 существ — бросок на каждое; больше — 10 бросков × число ÷ 10, вниз | совпало |
| Атака и защита | +5 % за очко до +300 %; −2,5 % за очко до −70 % | совпало |
| Удача | 1, 2, 3 из 24; +100 % к базовому урону, складывается с прибавкой за атаку; отрицательной в оригинале нет | совпало |
| Боевой дух | высокий: 1, 2, 3 из 24; низкий: 1, 2, 3 из 12 | совпало |
| Когда бросается высокий дух | после перемещения, удара, выстрела; не после «защищаться»; один раз за раунд | совпало |
| «Ждать» после второго хода | отдельная часть раунда перед остальными ждавшими | **в черновике не было, добавлено** |
| Высокий дух у ждавшего отряда | возможен | **в черновике не было, добавлено** |
| Равная скорость | сторона, ходившая не последней; в начале боя — нападающий; внутри стороны — по порядку в армии | совпало; это правило оригинала, а не своё |
| Ждавшие | ходят от медленного к быстрому | совпало |
| «Защищаться» | +20 % к защите | совпало; округление в источниках не найдено |
| Стрелок | вплотную не стреляет; в ближнем бою урон вдвое меньше, в ответном ударе тоже; дальше 10 клеток — вдвое меньше; запас выстрелов | совпало |
| Ответный удар | один за раунд; на ответ не отвечают | совпало |
| Бегство | только герой; армия теряется | совпало |

Источники:

- вики по Heroes 3: `heroes.thelazy.net` — страницы Combat, Damage, Morale, Luck, Ranged attack;
- открытый движок VCMI (`github.com/vcmi/vcmi`): `config/gameConfig.json` (расстановка, шансы боевого духа и удачи), `lib/battle/BattleHex.h` (сдвиг рядов и соседи).

Источники расходятся в одном: по VCMI ждавший отряд второго хода от боевого духа не получает, по вики — получает. Взято по вики: она описывает оригинальную игру.

Из источников взяты только правила и числа механик. Тексты, названия и характеристики существ не копировались (догма 1).

## Что согласовал владелец

Владелец согласился на все шесть пунктов 2026-11-12.

1. **Новая зависимость на шаге 2.4:** дополнение Capacitor «Ориентация экрана» (`@capacitor/screen-orientation`, от авторов Capacitor, лицензия MIT). Без него приложение не может само повернуть экран на время боя.
2. **Бой — отдельное состояние со своими командами.** На этапе 2 он живёт рядом с партией, а не внутри неё. На этапе 3 бой станет частью состояния партии, и сохранение посреди боя появится тогда же. На этапе 2 бой не сохраняется: закрыли приложение — бой начинается заново.
3. **Названия и числа существ** из `14-creatures.md`. Они свои намеренно: копировать существ оригинала нельзя (догма 1).
4. **Округление прибавки от «защищаться»:** дробная часть отбрасывается, но прибавка не меньше 1. В источниках точного правила нет.
5. **Простой компьютер** из `15-battle-ai.md` — свой. Как устроен компьютер в Heroes 3, не сверялось: умный противник — этап 5.
6. **Управление касаниями** из `16-battle-screen.md` — своё: оригинал рассчитан на мышь.

## Список приёмки

### После шага 2.3, в браузере

- [ ] В меню есть «Проверочный бой»; он открывает поле с двумя армиями.
- [ ] Видно, чей сейчас ход, и видна очередь ходов.
- [ ] Отряд ходит на подсвеченные клетки и не ходит на остальные.
- [ ] Летун перелетает через препятствие, пехотинец обходит.
- [ ] Удар уменьшает число существ во вражеском отряде; враг отвечает один раз за раунд.
- [ ] Стрелок стреляет издалека; когда враг стоит вплотную, не стреляет.
- [ ] «Ждать» переносит ход отряда в конец раунда, «Защищаться» пропускает ход.
- [ ] Противник ходит сам.
- [ ] Бой можно выиграть: появляется итог с потерями обеих сторон.
- [ ] Бой можно проиграть.
- [ ] «Бежать» заканчивает бой поражением.
- [ ] Иногда срабатывают боевой дух и удача; об этом пишет журнал боя.

### После шага 2.4, на телефоне

- [ ] На время боя экран сам становится альбомным, после боя возвращается.
- [ ] По клеткам и отрядам удобно попадать пальцем.
- [ ] Счётчик кадров в бою не опускается ниже 50.
