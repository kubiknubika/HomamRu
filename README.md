# Герои Ру

«Герои Ру» (репозиторий HomamRu) — это проект-клон игровых механик серии Heroes of Might and Magic (HoMM): пошаговая стратегия с исследованием карты, развитием городов, наймом армий и тактическими боями.

## Авторские права

Проект воспроизводит только игровые механики и не нарушает авторских прав:

- в проекте не используются оригинальные ресурсы игр серии — графика, музыка, звуки, тексты, карты и исходный код;
- не используются оригинальные названия, имена персонажей, существ, городов и элементы сюжета;
- весь код, графика и прочий контент создаются с нуля либо берутся из источников со свободной лицензией.

Проект является неофициальным, не связан с правообладателями серии Heroes of Might and Magic и не одобрен ими. Все упомянутые товарные знаки принадлежат их владельцам.

## Разработка

Проект целиком пишется ИИ-агентами (вайбкодинг). Обязательные правила разработки — в [AGENTS.md](AGENTS.md).

Стек: TypeScript, Phaser 4, React, упаковка под Android через Capacitor. Устройство проекта — в [docs/architecture.md](docs/architecture.md), планы — в [docs/roadmap.md](docs/roadmap.md).

```sh
pnpm install     # зависимости (нужны Node.js 22+ и pnpm 12)
pnpm run dev     # игра в браузере
pnpm run check   # полная проверка
pnpm run play    # проиграть сценарии в консоли
```
